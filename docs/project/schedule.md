2. 使用离线验收包，逐 case 从同一索引母本启动，完成静态、串行动态和 epoch 的小规模验证。
3. 验证旧快照稳定、新快照更新可见、reader 刷新及日志计数，然后才冻结硬件实验配置。
4. 执行正式多轮矩阵，分析真实延迟、吞吐与更新/刷新开销。
5. 基于真实证据完成报告、图表和答辩材料。
