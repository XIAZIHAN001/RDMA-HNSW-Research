## 实验范围

| 组别 | 条件 | 新实测轮数 |
| --- | --- | ---: |
| 四档主实验 | SIFT 1K、10K、50K、100K。四种策略。静态与 30% 随机更新 | 96 |
| SIFT 10K 粒度对照 | `prefix`，静态与 30% 更新，G=4/8/16。G=8 复用主实验 | 12 |
| SIFT 10K 参数敏感性 | `prefix`，粒度、缓存容量、更新比例、读线程数、随机与热点更新 | 30 |

各配置重复三轮。敏感性对照复用主实验中 SIFT 10K 的静态与 30% 更新 G=8 数据。JSON 的 `cohorts` 记录各组新增的实测轮次，`reused_main_controls` 记录对应的主实验轮次。

连接验收另有一轮 SIFT 1K 静态 IB 测试和 16 项 SIFT 1K CM 功能测试，最低已校验 Recall@10 均为 1.0。

## 复现设置

生成 128 维 SIFT 子集与 exact truth，再使用 Release 构建的 `storage_server` 和 `lab_epoch_client`。每轮从相同母本启动存储端。固定 M=16、efConstruction=100、efSearch=256、k=10 和 workload seed=42，每个读线程独立缓存并预热 1,000 条查询。[主实验数据准备](../../../experiments/docs/reproduce-main.md#数据准备) · [双端部署](../../../experiments/docs/rdma-migration.md#跨会话-epoch)

主实验固定 G=8、每读线程缓存 10,000 条、单读线程。静态每轮 10,000 条查询，30% 更新每轮 2,000 次操作，epoch 大小为 100。敏感性以 10K、G=8、容量 10,000、单读线程、10% 随机更新为共同对照。热点目标限制在前 1% 节点，随机和热点两组保持操作顺序与向量引用一致。

## 统计口径

- 查询吞吐为查询数除以查询阶段耗时。混合吞吐为查询与 upsert 的总数除以查询、更新与读端刷新阶段耗时之和。预热和真值校验单独计时。
- 查询延迟先按轮计算均值和分位数，再取三轮均值。图中误差线为三轮的样本标准差。相对变化率为同规模同负载的策略均值除以 `fixed` 均值再减 1。
- 总流量统计查询阶段成功完成的 RDMA 数据面 READ。邻接请求及浪费字节按策略层计数。每查询指标用该轮查询数归一化后再跨轮取均值。
- 静态查询全量校验 exact truth。混合负载按每个 epoch 中每个活跃读线程的首条查询校验对应快照。

四档主实验中，`prefix` 相对 `fixed` 的邻接请求字节减少 20.4%–47.5%，总 RDMA READ 字节减少 0.30%–1.25%，查询吞吐变化为 −3.97% 至 +0.32%。在 SIFT 10K、10% 更新下，G 从 1 增到 16 时，每查询邻接依赖 READ 从 5.86 次降到 0.57 次，浪费的邻接字节从 0 增到 7.23 KiB。
